◆ read_temp_job_recurring()

void read_temp_job_recurring ( void * args)

@breif: Function to recieve and calculate onboard temp.

This function increments its run count as it is recurring, reselects the ADC input incase another job changed it, reads the raw input from ADC, converts to volts and then to celsius, and logs the temperature as well as triggering a pico reset if the temperature reaches critical levels.
