SquidSat OBC Flight Software

Clone

After cloning the repo, initialize the submodules:

git submodule update --init --recursive

Build

Use build.sh to create/configure the build/ directory and compile the firmware for the Pico version you want:

./build.sh -p pico

or, for Pico 2:

./build.sh -p pico2

The -p flag selects the target board:

  • pico builds for RP2040.
  • pico2 builds for RP2350.

To build in debug mode, add -d:

./build.sh -p pico2 -d

Deploy

After the build finishes, flash the Pico with:

./deploy.sh

The first time you flash a pico, you will have to do the traditional drag and drop the uf2 file. This is due to the fact that we need to get usb initialized on the pico.
