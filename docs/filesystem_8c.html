Detailed Description

FatFs implementation for RTOS SMP with resource management.

Author
Tyler Nielsen
Version
0.1
Date
2026-06-24
Copyright
Copyright (c) 2026

Restrains the use of the file system to avoid using too many resources. Tasks that call FatFS functions should ask first (with the public functions) to get an instance of the fs_use counting mutex AND handle rejection (but this is not enforced on fatfs functions)
