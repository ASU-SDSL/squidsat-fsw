◆ add_can_transmission()

int add_can_transmission ( const can_message_t * msg)

Queue a CAN frame for transmission. Safe to call from any task (e.g. STEVE jobs). The frame is copied into the TX queue; can_task sends it when the MCP2515 is free. Waits up to 10 ms for space if the queue is full.

Parameters
msgFrame to send (copied, so the caller's struct can be reused right away)
Returns
0 if queued, -1 if the queue stayed full (frame dropped)

◆ can_task()

void can_task ( void * pvParameters)

FreeRTOS task that owns the MCP2515.

  1. Waits for a serial monitor so init logs aren't lost
  2. Initializes the MCP2515, retrying every second until it succeeds
  3. Loops forever: moves received frames into can_rx_queue and sends queued frames from can_tx_queue, one at a time

can_task_state (readable with the GSE "can_state" command): 1 = waiting for USB, 2 = initializing, 3 = init failed (retrying), 4 = running
