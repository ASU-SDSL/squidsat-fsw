Detailed Description

-— Queue Entries -— This is the way all the Log Entries are defined:

  1. timestamp - The time at which the log entry was created, recorded in FreeRTOS ticks via xTaskGetTickCount().
  2. level - The severity level of the log entry, defined by LogLevel. See LogLevel enum for all possible values.
  3. data - The log message itself, stored as a null-terminated string. Truncated to MAX_PACKET_SIZE - 1 characters if longer.
