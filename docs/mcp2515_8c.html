int mcp2515_init ( void )

Bring up the MCP2515: reset it, verify SPI comms, set 50 kbit/s bit timing, open both RX buffers to all frames, then switch to normal mode.

Returns
1 on success (chip in normal mode), 0 on any failure (caller should retry)

◆ mcp2515_send()

int mcp2515_send ( const can_message_t * m)

Load one CAN frame into MCP2515 TX buffer 0 and request transmission. Non-blocking: returns as soon as the frame is handed to the chip. A return of 0 means "queued on the MCP2515", not "delivered". Use mcp2515_tx_busy() to see when it's ACKed.

Parameters
mFrame to send (id, extended flag, dlc 0-8, data)
Returns
0 if the frame was loaded and transmission requested, -1 if the frame is invalid or TX buffer 0 is still busy with a previous frame

◆ mcp2515_spi_init()

void mcp2515_spi_init ( void )

Initialize the Pico SPI peripheral and pins for the MCP2515: CLK_SPEED baud, SPI mode 0 (CPOL=0, CPHA=0), 8-bit MSB-first, and chip select driven manually as a GPIO, idling high (deselected).

◆ mcp2515_tx_busy()

bool mcp2515_tx_busy ( void )

Check whether TX buffer 0 still has a frame waiting to be sent or acknowledged (TXREQ set).

Returns
true if TXB0 is busy (send pending or retrying), false if it is free for a new frame
